# ZARKOLIA NEWS · λήψεις εφαρμογών

**ZARKOLIA NEWS · Greek-language news, worldwide**

Ειδησεογραφική εφαρμογή για ελληνικές ειδήσεις, διαθέσιμη σε Windows και Android.

Η επίσημη τοποθεσία λήψης είναι η ενότητα **Releases** αυτού του δημόσιου αποθετηρίου. Εδώ δεν δημοσιεύεται ο πηγαίος κώδικας της εφαρμογής.

## Τι πρέπει να γνωρίζει ο χρήστης
- Όσα αρχεία έχουν την ένδειξη **pre-release / beta** είναι δοκιμαστικά.
- Το τωρινό πακέτο Windows χρειάζεται εγκατεστημένη Python.
- Τα πρώτα Android APK είναι δοκιμαστικά και η ψηφιακή τους υπογραφή δεν είναι ακόμη η σταθερή υπογραφή παραγωγής.
- Οι τωρινές εκδόσεις **δεν διαθέτουν ακόμη αυτόματη εγκατάσταση ενημερώσεων**. Μπορείς να ελέγχεις εδώ για νέες εκδόσεις.
- Η εφαρμογή συγκεντρώνει συνδέσμους και πληροφορίες από ελληνόφωνες ειδησεογραφικές πηγές. Τα δικαιώματα του δημοσιογραφικού περιεχομένου παραμένουν στους αντίστοιχους δικαιούχους.

**Κώδικας**: ιδιωτικό αποθετήριο, διαθέσιμο μόνο στον ιδιοκτήτη και στους εξουσιοδοτημένους συνεργάτες του.
